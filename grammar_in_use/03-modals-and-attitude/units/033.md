# Unit 33 — `should` 1

## A

Study this advice:

> “I keep waking up exhausted.”  
> “You should stop checking your phone so late at night.”

Use `should + base verb` to give advice or say what you think is right: *I think you should ask for a receipt.* / *Should we tell the organiser?* `Shouldn’t` means “this is not a good thing to do”: *You shouldn’t trust every online review.*

`Should` is weaker than `must` or `have to`. *You should apologise* is advice; *You must apologise* says there is no acceptable alternative.

## B

Use `should` for something that is expected or seems right: *The parcel should be here by noon.* / *The label should say 250 ml, not 25 ml.* *Rin has prepared carefully, so she should pass.* `Shouldn’t` can express a negative expectation: *It shouldn’t take more than ten minutes.*

## C

Use `should have + past participle` when a good past action did not happen: *You should have saved the document first.* `Shouldn’t have + past participle` means someone did an action that was unwise: *I shouldn’t have sent that message while angry.*

Compare *You should leave now* (advice now) with *You should have left earlier* (criticism or regret about the past).

## D

`Ought to` has a similar meaning to `should`, but it is followed by `to`: *You ought to rest.* / *They ought not to drive so fast.* / *You ought to have called.*

## Exercises

### 33.1

Complete with `should` or `shouldn’t`.

1. You look cold. You ___ put on a coat.
2. We ___ leave litter in the park.
3. The train left an hour ago, so it ___ be near the coast by now.
4. This repair ___ cost much; it is only a loose screw.

### 33.2

Complete with `should have` or `shouldn’t have`.

1. I missed the deadline. I ___ (start) earlier.
2. We ate the whole cake before dinner. We ___ (do) that.
3. The guests are still not here. They ___ (arrive) by now.

### 33.3

Rewrite using `ought to`.

1. You should read the instructions.
2. She should not have spoken so rudely.

<details>
<summary>Answers</summary>

33.1 1. should 2. shouldn’t 3. should 4. shouldn’t.

33.2 1. should have started 2. shouldn’t have done 3. should have arrived.

33.3 1. You ought to read the instructions. 2. She ought not to have spoken so rudely.
