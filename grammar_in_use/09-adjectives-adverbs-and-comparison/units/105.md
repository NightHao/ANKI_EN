# Unit 105 — Comparative forms

## A

Study two travel options:

> The ferry is slower, but it is more relaxing than the overnight bus.

Comparatives show a difference. Many short adjectives take **-er**: *smaller, brighter, cheaper*. Longer adjectives normally use **more**: *more convenient, more reliable*. Use **than** when you name the other person, thing, or situation: *This route is safer than the old one.*

## B

Spelling changes matter: *large → larger; thin → thinner; easy → easier*. Two-syllable adjectives ending in **-y** take **-ier**. Many `-ly` adverbs use **more**: *more carefully, more frequently*. Some two-syllable adjectives allow both forms: *quieter / more quiet; simpler / more simple*.

Do not combine the patterns: *more cheaper* and *more easier* are not standard. Say *cheaper* or *more expensive*.

## C

Some comparatives are irregular:

| Base form | Comparative |
|---|---|
| good / well | better |
| bad / badly | worse |
| far | farther or further |

Both *farther* and *further* can describe physical distance. Only **further** also means “additional”: *We need further information before deciding.*

## Exercises

### 105.1

Write the comparative form.

1. narrow → ___
2. comfortable → ___
3. early → ___
4. badly → ___

### 105.2

Complete the sentences.

1. This explanation is ___ (clear) than the first one.
2. Can you speak ___ (quietly), please?
3. The village is ___ (far) from the airport than I thought.
4. We need ___ details before we book anything. (far)

### 105.3

Correct the comparative in each sentence.

1. My new laptop is more lighter than my old one.
2. I work more carefully now, so I make less mistakes.

<summary>Answers</summary>

**105.1** 1. narrower  2. more comfortable  3. earlier  4. worse.  
**105.2** 1. clearer  2. more quietly  3. farther or further  4. further.  
**105.3** 1. My new laptop is lighter than my old one. 2. I work more carefully now, so I make fewer mistakes.
