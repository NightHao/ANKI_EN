# Unit 18 — `used to (do)`

## A

Study this contrast:

> “You take the bus everywhere now.”  
> “Yes, but I used to walk to work.”

Use `used to + base verb` for a repeated action in the past that no longer happens: *I used to collect stamps, but I gave them away.* It can also describe an earlier state that has changed: *This street used to be much quieter.* / *I never used to enjoy spicy food.*

It is not for one completed event. Say *I visited my aunt last Sunday*, not *I used to visit my aunt last Sunday.*

## B

`used to` is a past form; there is no present form `use to` with this meaning. Compare *He used to play chess* with *He plays chess now*. We can use it with `there`: *There used to be a post office by the bridge, but it closed.*

## C

In questions and negatives, the usual form is `did use to` / `didn’t use to`:

> “Did you use to wear glasses?”  
> “No, I didn’t use to need them.”

`Used not to` is possible but less common. After `did`, write `use`, not `used`.

## D

Do not confuse a former habit with an action in progress:

| Past habit, no longer true | Action in progress then |
|---|---|
| *I used to listen to the radio every night.* | *I was listening to the radio when the power failed.* |

The first describes a pattern; the second describes what was happening at one particular time.

## E

`be used to` has a different structure and meaning: *I am used to working late* means it is familiar or normal for me now. *I used to work late* means I did so in the past, perhaps not now.

## Exercises

### 18.1

Complete with `used to` and a suitable verb.

1. My grandmother ___ beside the sea, but she lives inland now. (live)
2. This room ___ a music shop. (be)
3. I ___ milk, but now I drink tea instead. (drink)

### 18.2

Make a question or negative sentence.

1. you / use / ride a bicycle to school?
2. I / not / use / like olives
3. there / not / use / be / so many tall buildings

### 18.3

Choose the correct form.

1. I **(used to work / was working)** in a café when my friend called.
2. I **(used to work / was working)** in a café during university, but not now.
3. She is used to **(drive / driving)** on the left.

<details>
<summary>Answers</summary>

18.1 1. used to live 2. used to be 3. used to drink.

18.2 1. Did you use to ride a bicycle to school? 2. I didn’t use to like olives. 3. There didn’t use to be so many tall buildings.

18.3 1. was working 2. used to work 3. driving.
