## Accuracy note

The source is a 398-page image-based scan, not a normal text PDF. Reading, Writing, Speaking, and Listening Unit 5 now provide readable Markdown lessons. Source scans are retained alongside exercises that depend on charts, diagrams, maps, tables, or other visual layouts. Recording Scripts and the Answer Key provide separate left/right column images.

The older broad/single-file OCR views were produced with PyMuPDF4LLM and Tesseract using the English `tessdata_fast` model at 300 DPI. They can contain recognition and reading-order errors and should not be treated as the authoritative reading view. The skill-chapter transcriptions were rebuilt in source-page order, with visual layouts retained where text alone is insufficient.

The source PDF itself omits printed pages 255–258 inside Practice Test 6. The extracted sequence therefore jumps from printed page 254 to 259; this is not an OCR omission.
