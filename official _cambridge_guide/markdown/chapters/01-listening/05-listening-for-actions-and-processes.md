## 2 Describing an Action or Process

When we describe how something works, we often use prepositions or adverbs to explain movement.

### 2.1 Show the direction

Draw or imagine an arrow that represents each underlined expression. Number 1 is already shown in the picture.

![Eight examples of movement: inside, through, upside down, along, beneath, around, upwards, and diagonally](assets/05-listening-for-actions-and-processes/movement-words.png)

[Open the movement image directly](assets/05-listening-for-actions-and-processes/movement-words.png)

1. Put it **inside** the box.
2. It then passes **through** a pipe.
3. Turn the container **upside down**.
4. The trolley moves **along** the tracks.
5. The area **beneath** the table was …
6. The paper was wrapped **around** the present.
7. This forces the air **upwards**.
8. Cut the paper **diagonally**.

<details>
<summary>Plain-English meanings</summary>

| Expression | Meaning |
|---|---|
| inside | into the inner part of something |
| through | in one side and out the other side |
| upside down | with the top turned to the bottom |
| along | following the length or direction of something |
| beneath | under something |
| around | surrounding or following the outside of something |
| upwards | toward a higher position |
| diagonally | at an angle, rather than straight across or straight up |

</details>

## Language Worth Keeping

| Pattern | Use | Example |
|---|---|---|
| **be used to + verb** | explain a tool's purpose | Scales are used to weigh things. |
| **cause + object + to + verb** | explain what produces an action | The spring causes the toy to bounce. |
| **force + object + direction** | describe pushed movement | The pump forces the water through a filter. |
| **pass through / move along / wrap around** | describe the path of movement | The chain passes around the wheel. |
| **First … Then … Next … Finally …** | present a process in order | First, measure the paper. Then, cut it. |

### Short production practice

Choose an everyday process, such as making coffee, using a washing machine, or wrapping a package. Describe it in four to six sentences using **First**, **Then**, **Next**, and **Finally**.
