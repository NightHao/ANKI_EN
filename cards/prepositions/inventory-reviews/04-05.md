## Major

1. **Merge the duplicate purpose contrast: `AR-PURPOSE-FOR` / `AR-PURPOSE-TO` — edit + exclude.**

   They are two halves of one retrieval decision: function with `for + V-ing`
   versus an agent's purpose with `to + base verb`. Keeping separate contrast
   rows produces two cards that each need the other answer. This is not the
   separate `prepositional to` versus infinitival `to` trap routed to 09.

   - Action: keep and edit `AR-PURPOSE-FOR`; exclude `AR-PURPOSE-TO` as
     duplicate coverage.
   - Replacement fields for `AR-PURPOSE-FOR`:
     `target_form=for + V-ing (function) / to + base verb (purpose)`;
     `meaning_or_distinction=Use for + V-ing for what a thing is for; use to + base verb for why an agent acts.`;
     `construction=noun + for + V-ing; verb + to + base verb`;
     `confusables=for + V-ing for personal purpose; so that + clause`;
     `card_type=contrast`;
     `notes=One contrast decision; infinitival to is not itself a preposition.`
   - Replacement fields for `AR-PURPOSE-TO`: `status=excluded`;
     `notes=Covered by AR-PURPOSE-FOR as the paired purpose contrast.`

2. **Merge the duplicate material contrast: `AR-MATERIAL-OF` / `AR-MATERIAL-FROM` — edit + exclude.**

   `made of` versus `made from` is one meaning contrast, not two atomic
   decisions. Two separate contrast cards would repeat the same choice.

   - Action: keep and edit `AR-MATERIAL-OF`; exclude `AR-MATERIAL-FROM`.
   - Replacement fields for `AR-MATERIAL-OF`:
     `target_form=made of / made from`;
     `meaning_or_distinction=Use made of when the original material remains recognizable; use made from when it has been transformed.`;
     `construction=be made of/from + material`;
     `confusables=made with + ingredient`;
     `card_type=contrast`.
   - Replacement fields for `AR-MATERIAL-FROM`: `status=excluded`;
     `notes=Covered by AR-MATERIAL-OF as the paired material contrast.`

3. **Merge the duplicate control contrast: `AR-CONTROL-UNDER` / `AR-CONTROL-IN` — edit + exclude.**

   The rows already name one another as confusables. A learner is choosing
   whether the thing is managed (`under control`) or a person/group directs it
   (`in control of`); one contrast card tests that decision fairly.

   - Action: keep and edit `AR-CONTROL-UNDER`; exclude `AR-CONTROL-IN`.
   - Replacement fields for `AR-CONTROL-UNDER`:
     `target_form=under control / in control of`;
     `meaning_or_distinction=Use under control for a situation that is managed; use in control of for the person or group directing it.`;
     `construction=be/keep/bring + under control; be + in control of + noun`;
     `confusables=out of control; take control of`;
     `card_type=contrast`.
   - Replacement fields for `AR-CONTROL-IN`: `status=excluded`;
     `notes=Covered by AR-CONTROL-UNDER as the paired control contrast.`

4. **`AR-AGE-AT` is routed to the wrong home — reroute to 01 Time.**

   the integrated inventory already covers this exact decision. Retaining the
   row in 04 creates a duplicate across subdecks.

   - Action: exclude this row in 04; retain the 01 Time item.
   - Replacement fields: `status=excluded`;
     `notes=Duplicate of TIME-AT-AGE; time meanings route to 01 Time under plan Section 3.2.`

5. **`AR-POSSESSION-OF` and `AR-CONDITION-IN` are too broad to test — exclude.**

   `the noun of noun` versus possessive `'s` is a broad noun-phrase grammar
   system, not one preposition retrieval decision. `in + condition/state`
   explicitly defers the necessary splitting until card authoring, which
   violates inventory atomicity and invites dictionary creep.

   - Action: exclude `AR-POSSESSION-OF` and `AR-CONDITION-IN`.
   - Replacement fields for both: `status=excluded`;
     `notes=Too broad for one retrieval decision; add a specific high-value chunk later only if a genuine gap remains.`

6. **`AR-CAUSE-FROM`, `AR-CAUSE-FOR`, and `AR-EXCHANGE-FOR` use verb-selected frames while filed as abstract meanings — edit/reroute.**

   The first two rows teach `suffer/recover/die from` and

   05 rows already cover several of them. The exchange row bundles three
   different verb constructions (`pay`, `sell`, `trade`) under a bare `for`
   label, so it cannot yield one fair card.

   - Action: edit `AR-CAUSE-FROM` to a non-lexical causal relation, edit
     `AR-CAUSE-FOR` to a non-lexical reason relation, and reroute/recast
     `AR-EXCHANGE-FOR` as a 05 verb pattern.
   - Replacement fields for `AR-CAUSE-FROM`:
     `construction=condition/result + from + cause`;
     `confusables=because of + cause; due to + cause`;
     `notes=Do not use suffer/recover/die examples; their selected frames belong to 05.`
   - Replacement fields for `AR-CAUSE-FOR`:
     `construction=action/decision + for + reason`;
     `confusables=because of + cause; for the purpose of`;
     `notes=Do not use apologize or punish examples; those selected frames belong to 05.`
   - Rerouted replacement row for `AR-EXCHANGE-FOR`:
     `item_id=VP-EXCHANGE-FOR`; `subdeck=05 Verb + Preposition`;
     `topic=exchange`; `target_form=exchange/trade + item + for + item`;
     `meaning_or_distinction=Use for to name what is received in return for an item given up.`;
     `construction=exchange/trade + noun + for + noun`;
