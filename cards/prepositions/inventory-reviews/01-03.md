# Phase 2 Independent Audit — Subdecks 01–03

**Reviewer:** Primary integration pass  
**Scope:** `01 Time`, `02 Place`, `03 Movement`  
**Source rows reviewed:** 147

## Major findings

1. **Overlapping time rows hide their true boundary.**
   - Items: `TIME-AT-CLOCK`, `TIME-AT-NOON-MIDNIGHT`;
     `TIME-ON-DAY`, `TIME-ON-DATE`; `TIME-FROM-TO`,
     `TIME-FROM-THROUGH`.
   - Consequence: later cards could repeat the same examples and violate the
     one-item-one-home rule.
   - Action: edit the first row in each pair so it covers only numeric clock
     times, named weekdays, or a `from ... to` range respectively. Retain the
     second row for the lexical exception or explicitly inclusive form.

2. **The weekend target contradicts its AmE explanation.**
   - Item: `TIME-ON-WEEKEND`.
   - Consequence: `at/on the weekend` on the target could teach the chiefly
     BrE form as an equal AmE production target.
   - Action: edit target to `on the weekend / on weekends`; keep the BrE form
     only in the source note, not the learner card.

3. **Office, hospital, and meeting pairs are duplicate decisions with
   substantial acceptable overlap.**
   - Items: `PLACE-IN-OFFICE` + `PLACE-AT-OFFICE`;
     `PLACE-IN-HOSPITAL` + `PLACE-AT-HOSPITAL`;
     `PLACE-AT-MEETING` + `PLACE-IN-MEETING`.
   - Consequence: separate single-answer cards would falsely mark a natural
     alternative wrong.
   - Action: retain one contrast item per pair that teaches viewpoint and
     accepts overlap; exclude the duplicate row.

4. **The school inventory omits the common AmE enrollment meaning.**
   - Item: missing after `PLACE-AT-SCHOOL`.
   - Consequence: `at school`, `in school`, and `in the school` cannot be
     distinguished accurately.
   - Action: add `PLACE-IN-SCHOOL-ENROLLED`, target `in school`, meaning
     “enrolled in or attending an educational program,” construction
     `be/still + in school`, confusables `at school; in the school`, type
     `contrast`, register `neutral`.

5. **The island row can create a false AmE prohibition.**
   - Item: `PLACE-ON-ISLAND`.
   - Consequence: both `on Maui` and `in Maui` can be natural under different
     physical-landmass versus regional viewpoints.
   - Action: edit into an explicit viewpoint contrast and require `Also OK:`
     whenever the Front does not force the physical-landmass reading.

6. **Three near-synonym location rows cannot fairly use single-answer
   contrast prompts.**
   - Items: `PLACE-BESIDE-NEXT`, `PLACE-NEAR-BY`, `PLACE-OPPOSITE`.
   - Consequence: two normal answers are built into each target.
   - Action: change to `chunk` cards or design meaning contrasts that accept
     both listed equivalents.

7. **Movement-specific direct-object rows duplicate the canonical grammar
   traps.**
   - Items: `MOVE-REACH-DIRECT`, `MOVE-APPROACH-DIRECT`; the already excluded
     `MOVE-ENTER-DIRECT` demonstrates the correct treatment.
   - Consequence: the same zero-preposition decision would receive two homes.
   - Action: expand `TRAP-DIRECT-REACH-DESTINATION` and
     `TRAP-DIRECT-APPROACH` as necessary, then exclude the movement duplicates.

8. **Two unrelated destination adverbs are combined.**
   - Item: `MOVE-GO-DOWNTOWN-ABROAD`.
   - Consequence: a learner could know one expression but not the other, and
     one Anki grade could not represent both.
   - Action: split into `MOVE-GO-DOWNTOWN` and `MOVE-GO-ABROAD`.

9. **The `around` row contains materially different path meanings.**
   - Item: `MOVE-AROUND`.
   - Consequence: circling an area, moving within an area, and avoiding an
     obstacle do not support the same answer cues.
   - Action: split at least `around + obstacle` from
     `around + area/route`, with context-specific meanings.

10. **Two high-value destination patterns are missing.**
    - Missing: `arrive home` with no preposition; `leave for + destination`.
    - Consequence: the source/goal system remains incomplete even though it
      includes `arrive at/in` and `leave/depart from`.
    - Action: add one repair item for `arrive home` and one context/chunk item
      for `leave for + destination`.

## Minor findings

1. `TIME-IN-SEASON` should allow both `in winter` and `in the winter` in AmE.
2. `TIME-NO-ALL` should describe `for all day` as unnatural for the intended
   simple-duration reading, not universally “nonstandard.”
3. `TIME-OVER-TIME` contains the typo `Omtime`; replace it with `overtime`.
4. `PLACE-ON-CALL` should note that `in a call` is also natural in software
   status/interface contexts.
5. `MOVE-DEPART-FROM` should not imply that `leave Gate 4` is generally wrong;
   the form can naturally describe a departure origin.
6. `MOVE-GO-HOME` can state the productive destination-adverb pattern with
   `go/come/get/drive/walk home`, while keeping one retrieval decision.
