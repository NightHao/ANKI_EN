# Unit lesson specification

Every lesson is an independently written companion to the correspondingly numbered
unit in *English Grammar in Use* Fifth Edition. It keeps the source book's teaching
rhythm without copying its prose, examples, exercises, or answer key.

## Required format

```markdown
# Unit N — Topic

## A

Study this example situation:

> A short, original situation or exchange that makes the grammar necessary.

Explain the first rule from the example. Use natural teaching language such as
`We use ...`, `We say ...`, and `(not ...)`.

## B

Develop the next real distinction. Give several original examples and explain what
changes in meaning.

## C

Use this section only when the topic has another important pattern, limitation, or
contrast. A small `Compare` table is appropriate when two forms are easily confused.

## D

Use this section only when a fourth distinction genuinely belongs in the unit.

## E

Use this section only when the source unit contains a fifth important use or pattern.

## Exercises

### N.1

Give one focused exercise set.

### N.2

Give a second exercise type that tests a different distinction.

<details>
<summary>Answers</summary>

List complete answers by exercise and item number. Add a short reason where more than
one answer may look possible.

</details>
```

## Teaching style

- Begin with meaning in a concrete situation, then name or explain the form.
- Organise the explanation as two to five lettered sections (`A`–`E`) according to
  the grammar itself. Do not add empty or repetitive sections.
- Prefer `We use ...`, `We say ...`, `We do not normally say ...`, `Compare ...`,
  `You can also ...`, and short parenthetical meanings.
- Show contrasts beside each other when the learner must choose between forms.
- Use `(not ...)` only for a genuinely unacceptable or misleading form. Do not label
  a natural alternative as wrong merely because it has a different focus.
- Include five to ten original examples across the explanation. At least two should
  sound natural in conversation.
- Include two to five exercise sets. Vary the operation when useful: complete,
  choose, correct, combine, transform, or write a true sentence.
- Keep answers in one collapsible block so the learner can work before checking.
- Cross-reference another unit only when it prevents a misleading oversimplification.

## Constraints

- Write entirely in English.
- Target 280–650 words, including exercises and answers.
- Preserve the source unit number and grammar topic.
- Before writing, inspect the corresponding source unit's explanation page. Cover
  every important A–E distinction taught there, not merely the broad title in the
  manifest, and do not import a later unit's main lesson as a substitute.
- Write new explanations, situations, examples, exercises, and answers.
- Do not reproduce distinctive source wording, named characters, exercise sequences,
  diagrams, or answer-key items.
- Prefer clear international English and examples transferable to conversation.
- Do not force every unit into the same number of sections or exercises.
- Avoid motivational filler, generic production prompts, and repeated template prose.
